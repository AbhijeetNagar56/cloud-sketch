# CloudSketch Design Guidelines

## 1. Page Routes
* **Home (`/`)**: Landing page with 2 options (Cloud Architecture / DevOps Pipeline).
* **Create Cloud (`/create/architecture`)**: System architecture canvas.
* **Create DevOps (`/create/devops`)**: CI/CD pipeline canvas.
* **Saved Projects (`/saved`)**: Local storage diagram manager.
* **About (`/about`)**: App overview and tech stack.

## 2. Design System
* **Theme**: Light Mode
* **Background**: `#F8FAFC` (Canvas fill)
* **Surface**: `#FFFFFF` (Cards & panels)
* **Borders**: `#E2E8F0` (Slate 200)
* **Primary Accent**: `#2563EB` (Blue 600 - Architecture)
* **Secondary Accent**: `#EA580C` (Orange 600 - DevOps)
* **Typography**: `Inter` (UI) / `JetBrains Mono` (Tech Tags)

## 3. Node Category Colors
* **Frontend**: Blue (`#2563EB`)
* **Backend**: Emerald (`#059669`)
* **Database**: Purple (`#7C3AED`)
* **Storage**: Orange (`#EA580C`)
* **Load Balancer**: Sky (`#0284C7`)
* **Cache / Queue**: Pink (`#DB2777`)
